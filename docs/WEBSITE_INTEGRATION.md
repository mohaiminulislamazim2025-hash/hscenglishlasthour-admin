# Storefront integration

The admin dashboard and the public Nuri Shirt Store share **one Supabase
project** and **one private storage bucket** (`nuri-product-images`).

## What the dashboard writes

- `products` rows (name, description, price, stock, availability, sort order).
- `products.image_path` (via the signed-upload + finalize flow).
- `orders.status` (forward-only transitions).
- `store_settings.delivery_charge_bdt` (single row `id = 1`).

## What the storefront reads

- Available products and their images (resolved from `image_path`).
- `store_settings` for the delivery charge / currency.

## Storage path contract

Images are stored at `products/{productId}/image.{ext}`. This must match the
storefront's storage-path module exactly so uploads are picked up automatically.

## Order status values

`pending`, `confirmed`, `packed`, `shipped`, `delivered`, `cancelled`.
Transitions are forward-only; `cancelled` is reachable from any non-terminal
state; terminal states (`delivered`, `cancelled`) cannot transition further.

## Notes

- Product ids are UUIDs generated by the database. The dashboard creates the
  product first, then uploads its image.
- The dashboard renders previews with signed URLs, so it works whether or not
  the bucket is public. The bucket should remain private.
